# hayame

**hayame**（速め）は、YouTube の動画で人が喋っていない（音がほぼない）区間だけを自動で速く再生し、間を詰める Chrome 拡張です。Chrome 標準の Picture-in-Picture をショートカットで開くこともできます。

## 機能

- 無音の区間だけを無音速度（既定 3 倍）で再生し、発話に戻ったらすぐ元の速度に戻す
- 無音のしきい値は、直近の音量から自動で決める
- `⌥P` で、再生中の動画を Chrome 標準の Picture-in-Picture で開く／戻す。PiP 中も倍速は効く
- ツールバーのアイコンのバッジで状態がわかる

対象は `https://www.youtube.com/*` だけです（PiP のショートカットはどのサイトでも使えます）。

## インストール

Chrome ウェブストアには公開していないので、パッケージ化されていない拡張機能として読み込みます。

1. 拡張機能のファイルを用意する。次のどちらか
   - [リリース](https://github.com/cy-takeuchi/chrome-extensions/releases)から `hayame-X.Y.Z-chrome.zip` をダウンロードして展開する
   - ソースからビルドする

     ```sh
     git clone https://github.com/cy-takeuchi/chrome-extensions.git
     cd chrome-extensions
     pnpm install
     pnpm hayame build   # packages/hayame/.output/chrome-mv3 にできる
     ```

2. Chrome で `chrome://extensions` を開き、右上の「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」で、展開したフォルダ（ビルドした場合は `packages/hayame/.output/chrome-mv3`）を選ぶ

## 使い方

YouTube で動画を再生すると、自動で動きます。速度は YouTube の UI で普段どおり変えられ、その速度（基準速度）を無音の間だけ無音速度に上げます。基準速度の方が速いときは、無音でも基準速度のままです。

### ポップアップ

ツールバーのアイコンを押すと開きます。

| 項目 | 既定 | 説明 |
|---|---|---|
| ON / OFF | ON | OFF にすると基準速度に戻して止まる |
| 無音速度 | 3.00x | 無音の間の速度。Chrome は 4 倍を超えると音声をミュートするので 4 倍まで |
| しきい値 | 底 +6 dB | 推定したノイズの底にこれを足した値を下回ると無音の候補にする。上げると無音と判定しやすくなる |
| 最短時間 | 300 ms | しきい値を下回る状態がこれだけ続いたら無音にする（動画の時間で測る） |

下半分には、いまのタブの解析の状態（RMS、声の大きさ、ノイズの底、しきい値、判定、playbackRate、基準速度）がリアルタイムで出ます。

「ログを保存」を押すと、直近 2 分の計測（RMS、声の帯域の RMS、声の大きさ、ノイズの底、しきい値、判定、速度など）を CSV で保存します。判定がおかしいと感じたときに、判定のロジックを調整する材料にします。

### バッジ

| バッジ | 状態 |
|---|---|
| `ON`（緑） | 動作中（発話、一時停止中、統計を集めている途中など） |
| `3x`（青） | 無音を倍速中。数字はいまの速度 |
| `!`（赤） | 解析できない。倍速せず、基準速度のまま。理由はアイコンにカーソルを載せるか、ポップアップで見られる |
| `OFF`（灰） | OFF |
| `PiP`（赤、3 秒） | ⌥P で PiP を開けなかった |

### ショートカット

| キー | 動作 |
|---|---|
| `⌥P` | 再生中の動画（複数あれば表示面積が最大のもの）を PiP で開く。PiP 中なら戻す |

キーは `chrome://extensions/shortcuts` で変えられます。

## 仕組み

YouTube の DOM 構造や内部 API には依存せず、Web 標準の API だけを使います。

- 音声は `video.captureStream()` から `AudioContext` の `AnalyserNode` に流して解析する。再生音の経路には触らない（`createMediaElementSource()` は使わない）ので、解析に失敗しても再生音は消えない
- 40ms ごとに RMS（dBFS）を測り、直近 1 分（動画の時間）の分布からしきい値を決める。1 分たまるまでは集まった分をすべて使う（判定は 5 秒分たまってから始める）。倍速にした区間はサンプルが減るので、各サンプルを表す動画の長さで重みを付ける
  - 上位 5% を声の大きさとし、それより 25dB 以上小さい音を間の候補にする。候補の中央値をノイズの底とし、しきい値 = ノイズの底 + オフセット とする
  - 下位 10% をそのままノイズの底にすると、喋り続ける動画では下位 10% が小さめの声（語尾や弱い音節）になり、しきい値が声の分布の中に入って、喋っている途中を無音と判定してしまう。声の大きさから離れた音だけを間とみなすことで、これを防ぐ
- 発話中は「しきい値 − 2dB」を下回る状態が最短時間続いたら無音にし、無音中はしきい値以上になった時点ですぐ発話に戻す。先読みはしないので、発話の頭が少し詰まって聞こえることがある
- 一時停止・シーク・バッファリング・ミュートの間は判定せず、統計にも入れない
- 拡張が `playbackRate` を変えたときはその値を覚えておき、`ratechange` で違う値になっていたら、拡張以外（YouTube の UI など）が変えたとみなして基準速度にする
- 同じ `<video>` のままソースが変わったら（SPA での画面遷移や広告）、統計を捨てて、新しく足された音声トラックにつなぎ直す。`<video>` が差し替わったら選び直す
- 次のときは倍速にせず、基準速度に戻す: captureStream が失敗した、音声トラックがない、AudioContext が止まっている、直近 30 秒ずっと音が取れていない（しきい値の統計より短い期間で見て、取れなくなったらすぐ気づくようにする）、間の候補が直近の 3% に満たない（喋り続けている、BGM が続いているなど、声と区別できる間がない）、速度をほかから何度も戻される
- OFF にしたとき、ページを離れるとき、拡張を更新・無効にしたときは基準速度に戻す
- PiP は `commands` で受け、`scripting.executeScript` で再生中の動画の `requestPictureInPicture()` を呼ぶ。ショートカットを押したタブには activeTab で一時的に注入でき、ユーザー操作中として実行される

### 制限

- 自動再生の制限で AudioContext が止まったまま作られることがある。ページを一度クリックするかキーを押すと再開する（それまではバッジが `!`）
- ミュート中は判定しない
