このページでは、Chrome 拡張機能「hoi」（以下「本拡張機能」）が扱う情報と、その扱い方を説明します。

扱う情報

情報 使い道 保存・送信先
GitHub の Personal Access Token GitHub の API を呼び出すため ブラウザの chrome.storage.sync。Chrome の同期を有効にしている場合は、同じ Google アカウントの Chrome に同期されます
登録先の GitHub Projects の URL 登録先の Project を特定するため 同上
選択したテキスト、開いているページの URL、kintone のコメントのパーマリンク Draft Issue の本文にするため ダイアログで「Project に追加」をクリックしたときにだけ、入力したタイトル・本文とともに GitHub の API（api.github.com）に送ります。本拡張機能の中には保存しません

収集しない情報

  • 閲覧履歴や、ショートカットを押していないページの内容は読み取りません。
  • 利用状況の計測（アクセス解析）や広告のための情報は収集しません。
  • 開発者のサーバーはありません。GitHub 以外の第三者に情報を送ることはありません。

権限の用途

権限 用途
storage トークンと Project の URL を保存するため
activeTab ショートカットを押したタブにダイアログを表示するため
scripting 本拡張機能を入れる前から開いていたタブでショートカットを押したときに、そのタブにダイアログを表示するスクリプトを読み込むため。ショートカットを押したタブにだけ読み込みます
すべてのサイトで動くコンテンツスクリプト どのページでも、ショートカットを押したときに選択中のテキストを読み取ってダイアログを表示するため。ショートカットを押すまでは何もしません。kintone の画面では、選択したコメントのパーマリンクをページ内から読み取ります

GitHub への送信について

GitHub に送った情報は、GitHub のサービスの一部として扱われます。GitHub での取り扱いは GitHub のプライバシーステートメント を見てください。

情報の削除

オプション画面でトークンと URL を空にして保存するか、本拡張機能をアンインストールすると、保存した情報は削除されます。GitHub に登録した Draft Issue は GitHub 上で削除してください。

お問い合わせ

本ポリシーや本拡張機能についての質問は、 GitHub の Issues にお寄せください。

改定

本ポリシーを変更した場合は、このページで公開し、最終更新日を更新します。
