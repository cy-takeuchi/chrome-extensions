utsushi のプライバシーポリシー

最終更新日: 2026 年 10 月 5 日

このページでは、Chrome 拡張機能「utsushi」（以下「本拡張機能」）が扱う情報と、その扱い方を説明します。

扱う情報

情報 使い道 保存・送信先
kintone のレコード、コメント、フォームの定義 テンプレートに差し込んでテキストにするため ショートカットを押したときに、開いている kintone から kintone の REST API で読み取ります。作ったテキストはクリップボードに書くだけで、本拡張機能の中には保存しません
kintone のレコードの添付ファイル 一括ダウンロードのため kintone から、パソコンのダウンロードフォルダに保存します
プリセット（テンプレート）とダウンロード設定 次回以降も同じ形式でコピーするため ブラウザの chrome.storage.local。kintone のドメインとアプリ ID ごとに保存します。同期はしません

kintone へのアクセスには、ブラウザでログイン中の kintone のセッションを使います。ID やパスワードを本拡張機能が扱うことはありません。

収集しない情報

  • kintone 以外のサイトでは動きません。
  • 利用状況の計測（アクセス解析）や広告のための情報は収集しません。
  • 開発者のサーバーはありません。読み取った情報を kintone 以外の第三者に送ることはありません。

権限の用途

権限 用途
https://*.cybozu.com/*、https://*.kintone.com/* kintone の画面にプリセットの画面を表示し、REST API でレコードを読み取るため
clipboardWrite 作ったテキストをクリップボードに書くため
downloads 添付ファイルを一括ダウンロードするため
storage、unlimitedStorage プリセットを保存するため。プリセットが多くなっても保存できるように容量の制限をなくしています

情報の削除

オプション画面から、プリセットをアプリごとに、またはすべて削除できます。本拡張機能をアンインストールすると、保存した情報はすべて削除されます。ダウンロードしたファイルとクリップボードの内容は、パソコン上で削除してください。
