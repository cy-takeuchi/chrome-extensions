kintone の Chrome 拡張機能
hoi utsushi GitHub

kintone の作業を、もう少し楽に

kintone のコメントやレコードを、ほかのツールへ手早く持ち出すための Chrome 拡張機能です。どちらも無料で、ソースコードを公開しています。

hoi

kintone などの画面で選択したテキストを、元ページへのリンク付きで GitHub Projects に Draft Issue として登録します。kintone のコメントを選択した場合は、そのコメントのパーマリンクを付けます。

詳しく見る

utsushi

kintone のレコードとコメントの内容をテンプレートに差し込んで、クリップボードにコピーします。添付ファイルの一括ダウンロードもできます。
